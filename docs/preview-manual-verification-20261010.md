## 범위와 근거
사용자가 브라우저에서 진행하고 채팅으로 결과를 확인했다. 자동 실행 로그·스크린샷·DB 행수 대조를 확보한 시험이 아니다. 가상 기록만 사용했으며 개인 식별자와 확인 링크를 기록하지 않는다. 기존 테스트 계정은 유지했다.

## 확인한 결과
- 신규 계정: 로그인 후 동의 화면 표시. 동의 전 내 기록은 빈 목록이고 오늘 기록 입력은 차단됨. 저장 RPC 직접 거부까지 시험한 것은 아님.
- 동의 후 가상 기록 저장 성공 안내. 내 기록 새로고침 후 한 개 유지.
- 메모 수정 후 새로고침에서 수정 내용과 한 개 유지.
- 기록 삭제 후 새로고침에서 빈 목록 유지.
- 로그아웃 후 뒤로 가기에서 로그인 안내 표시.
- 기존 A/B 계정으로 전환하여 각 계정의 기존 가상 기록 표시 확인. 신규 시험 기록은 이미 삭제되어, 다른 계정에 그 메모가 없다는 결과를 분리 근거로 사용하지 않음.
- B에서 Offline 저장 실패 안내와 메모 유지. No throttling 복구 후 재시도 성공 안내. 새로고침 후 시험 메모 정확히 한 개. 시험 종료 후 해당 가상 기록만 삭제했다고 사용자 확인.
- 두 탭에서 B 조회를 Slow 3G로 시작하고 다른 탭 로그아웃/A 로그인 진행. 원래 탭 로그아웃 안내, 다시 연 내 기록에서 A 기록만 표시. 응답 도착 순서가 통제되지 않아 늦은 B 응답 차단 시험 완료로 판정하지 않음.

## 인증 환경과 미검증
사용자가 분리 테스트 프로젝트의 Confirm email 켜짐, 미리보기 callback Redirect URL 추가를 확인했다. 최초 메일 링크는 localhost 연결 거부로 끝났고 테스트 Site URL이 localhost임을 확인했다. 별도 승인 후 사용자가 Site URL을 위 미리보기 origin으로 변경했다. 템플릿 소스는 조회하지 못해 localhost 이동의 정확한 원인은 확정하지 않았다. 이후 새 계정 비밀번호 로그인은 동의 화면으로 이동했다. 이메일 확인 완료를 시사하지만 전용 /auth/complete의 실제 코드 교환 성공을 검증한 결과가 아니다.

## 다음 시험
1. 실제 확인 링크: 기존 계정 재생성·삭제 없이 재발송 가능 여부와 원래 가입 브라우저의 PKCE 조건을 먼저 확인. 링크 원문을 채팅·로그에 남기지 않는다. /auth/complete 도착, 선택 전 자동 교환 없음, 명시 선택 후 성공/실패를 별도 기록한다. 필요한 새 계정·메일 발송은 사용자와 시험 조건을 확정한다.
