# 도움 화면 출처 기록

출시 전, 그리고 정기적으로 **사람이 직접** 다시 확인한다.

마지막 확인: 2026-10-08 (Claude, 웹 검색·누리집 열람)

## 바꾼 이유 (2026-10-08)
- 이전 문구 "무료로 상담을 받을 수 있어요", "1577-0199로 전화하면 가까운 센터로 연결해 줘요"는 공식 출처로 일괄 보장할 수 없어 삭제·완화.
- 각 연락처 아래 출처 링크, 화면 하단에 확인 날짜 표시.

## 아직 확인할 것
- 119·112·109 보도자료 본문을 사람이 직접 열어 문구 확인.
- 도움 화면 자체의 오프라인 재방문은 지원하지 않는다. 서비스 워커·앱 캐시는 사용하지 않는다.

## 연락처 파일 저장 (2026-10-10)
- `/help/contact-card`에서 현재 `contacts.ts`의 연락처·안내·확인 날짜·출처 링크를 UTF-8 텍스트 파일로 내려받는다. 연락처를 별도 복사본으로 관리하지 않는다.
- 미리 내려받은 파일은 인터넷 없이 읽을 수 있다. 오프라인 첫 방문이나 도움 화면 자체의 오프라인 접근은 보장하지 않는다.
- 전화 연결에는 통신망, 출처 링크 열람에는 인터넷이 필요하다. 저장본에는 운영 방식 변경 가능성과 최신 도움 화면 주소를 표시한다.
- 로그인·Supabase·사용자 기록 없이 파일을 만든다. 기존 안내 내용과 확인 날짜는 그대로 유지하며, 이번 작업을 연락처 재검증으로 표시하지 않는다.
- PRD v3.1 F01/D03의 다운로드 안내 지원에 해당한다. 계정 삭제와 자동 오프라인 재방문 지원은 별도 과제다.
