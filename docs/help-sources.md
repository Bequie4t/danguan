# 도움 화면 출처 기록

출시 전, 그리고 정기적으로 **사람이 직접** 다시 확인한다.

## 바꾼 이유 (2026-10-08)
- 이전 문구 "무료로 상담을 받을 수 있어요", "1577-0199로 전화하면 가까운 센터로 연결해 줘요"는 공식 출처로 일괄 보장할 수 없어 삭제·완화.
- 각 연락처 아래 출처 링크, 화면 하단에 확인 날짜 표시.

## 아직 확인할 것
- 119·112·109 보도자료 본문을 사람이 직접 열어 문구 확인.
- 오프라인 상태에서 도움 화면 접근: 현재 서비스 워커가 없어 **오프라인에서는 열리지 않는 구조**(브라우저 캐시에 남아 있으면 우연히 보일 수 있음). 별도 결정 필요.
