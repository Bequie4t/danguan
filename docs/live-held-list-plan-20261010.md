# 실제 조회 지연 시험 실행안

상태: 스크립트 준비 및 node --check 통과. 실제 Chrome/실제 계정 시험 미실행.
스크립트: scripts/verify-live-held-list.mjs. 기능 기준 bdb1a39, 고정 분리 TEST 미리보기 83g42kpgh. 배포 SHA는 스크립트가 자동 검증하지 않으므로 실행 전 Vercel 메타데이터로 대조해야 한다.

## 준비 조건
- 실제 건강 기록이 없는 기존 A/B 테스트 계정과 구별 가능한 가상 메모가 각각 존재해야 한다. 내용·UID·토큰은 결과에 저장하지 않는다.
- Playwright는 기존 시험 환경의 설치를 재사용한다. 프로젝트 의존성은 추가하지 않는다. 시스템 Chrome이 필요하다. 자동화 Chrome의 Vercel 로그인 차단이 계속되면 시험을 중단한다. 보안 설정 해제·원격 디버깅·로그인 상태 파일 저장으로 우회하지 않는다.
- 이전 수동 로그인 세션을 재사용하지 않는 임시 브라우저 컨텍스트이다. Vercel 인증과 앱 A/B 로그인은 사용자가 직접 입력한다. Enter 입력 없음.

## 실행
Playwright가 설치된 기존 시험 폴더에서 이 스크립트를 실행할 수 있다. 다른 위치에서는 TEST_PLAYWRIGHT_MODULE을 설치된 playwright/index.mjs의 절대 경로로 설정한다. 기존 실행 프로세스가 없는지 확인하고 한 번만 실행한다.

1. 첫 탭에서 A 로그인 후 내 기록을 연다. 스크립트가 A 목록을 확인하고 다시 불러오기를 누른다.
2. 서버의 실제 A 목록 응답을 가져온 뒤 브라우저 전달을 보류한다. 기록 쓰기는 하지 않는다.
3. 두 번째 탭의 로그인 폼에서 B로 직접 로그인하고 내 기록을 연다. 로그아웃 버튼을 누르면 원래 탭이 이동하며 요청이 취소될 수 있어 누르지 않는다.
4. 실제 B 목록의 소유자가 A와 다름을 확인한 뒤 보류 A 응답을 전달한다.
5. 정확히 보류한 요청의 브라우저 응답 도착을 확인하고 원래 탭의 계정 전환 안내와 A 전용 가상 메모 부재를 확인한다.

## 판정과 한계
다른 Supabase 프로젝트와 기록 변경 요청을 차단한다. 인증 로그인 요청은 분리 TEST 서버에서 진행한다. 스크린샷·세션 파일·헤더·응답 본문·메모·UID를 저장하지 않는다. result.json은 단계와 검사 이름/불리언, 고정 공개 환경 주소만 기록한다. 예외 본문은 출력하지 않는다.
응답 취소·로그인 차단·다른 계정 확인 실패는 통과가 아니다. 실제 A 응답 보류, B 확인, A 전달의 순서를 각각 확인해야 한다. UI 관찰 창은 1.5초이며 모든 경쟁을 증명하지 않는다. 저장/삭제/토큰 갱신/가입 확인 경쟁을 포함하지 않는다. 시험 종료는 새 컨텍스트만 닫고 기존 사용자 브라우저 세션과 가상 기록을 변경하지 않는다.

ChatGPT가 구현과 자체 검토를 수행했다. 실제 시험 성공으로 보고하지 않는다. 운영 배포/DB/main 변경 없음.
