최신 PR 설명과 이 문서를 기준으로 검토한다. 운영 소스 대조와 남은 실제 환경 시험의 처리 여부를 결정한다. 병합·운영 배포는 사용자 별도 지시가 필요하며 이 문서의 작성이나 시험 통과가 그 승인을 대신하지 않는다. 제품 기능·결제 구현보다 계정 보호와 저장 검증을 우선한다.
